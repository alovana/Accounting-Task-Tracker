# Screen List

## 1. Login
- username/password
- forgot password (future)

## 2. Staff Dashboard
- งานของฉันวันนี้
- งานค้าง
- งาน blocked
- ลูกค้าที่รับผิดชอบ
- แจ้งเตือนล่าสุด

## 3. Manager Dashboard
- ภาพรวมทีม
- งานค้างแยกตามพนักงาน
- งาน blocked แยกตามลูกค้า
- % งานเสร็จตรงเวลา
- leaderboard / performance summary

## 4. Customer List
- ตารางลูกค้า
- filter ตามประเภทธุรกิจ / ผู้รับผิดชอบ / สถานะ

## 5. Customer Detail
- ข้อมูลลูกค้า
- รอบงานรายเดือน
- checklist ล่าสุด
- ประวัติ blocker

## 6. Business Type Management
- เพิ่ม/แก้ไขประเภทธุรกิจ

## 7. Checklist Template List
- รายการ template
- filter ตามประเภทธุรกิจ

## 8. Checklist Template Editor
- เพิ่ม/ลบ/reorder item
- ตั้ง required / due offset

## 9. Monthly Work Board
- ดูงานตามเดือน
- แสดง status per customer
- filter ตามพนักงาน / สถานะ / ลูกค้า

## 10. Work Item Detail
- สถานะ
- note
- blocked reason
- history

## 11. Team Performance Report
- รายงานผลงานรายคน / รายเดือน

## 12. Notification Settings
- เปิด/ปิด Line OA events
- ตั้งค่าผู้รับแจ้งเตือน

## 13. User Management
- จัดการผู้ใช้งานและสิทธิ์

## 14. System Settings
- ค่าทั่วไปของระบบ
- policy การสร้างงานรายเดือน
